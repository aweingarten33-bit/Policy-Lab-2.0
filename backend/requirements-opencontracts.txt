# What OpenContracts needs to be importable inside this process.
#
# Policy Lab calls OpenContracts as a library, not as a service: their CFR
# provider, their AuthoritySourceRecord and their candidate_keys run in the
# FastAPI worker. That is deliberately the simplest integration that runs their
# real code -- no Postgres, no Celery, no GraphQL, no second container.
#
# The cost is this file. Their authority modules import Django models at load
# time, so the app registry has to be populated before any of them can be
# imported, and populating it drags in most of their web stack even though
# none of it is used. Nothing below is called by Policy Lab; every entry is
# here to satisfy an import that happens on the way to code that is.
#
# Installed separately from requirements.txt so a deployment that does not
# verify federal citations does not carry it. Without it the authority
# substrate degrades to the legacy path, which /api/health reports as
# authority_provider_degraded=true rather than failing quietly.
#
# OpenContracts itself is not on PyPI. Point OPENCONTRACTS_SRC at a checkout:
#   git clone https://github.com/Open-Source-Legal/OpenContracts /opt/opencontracts
#   OPENCONTRACTS_SRC=/opt/opencontracts
#
# Verified against OpenContracts at aaafcb2.
